AND Gate (7408) Logic Output Experiment

A practical electronics laboratory experiment designed to verify the logical output and proper functionality of quad AND gates using the 7408 integrated circuit IC on a breadboard

Components and hardware used
- Digital IC: 7408 Quad 2-input AND Gate (14-pin DIP)
- Breadboard: Pin-type educational testing board
- Output Indicators: 4 LEDs (Light Emitting Diodes)
- Power Supply: DC Power Supply (5V Vcc)
- Wiring: Jumper wires

Circuit connections and pinout
- Pin 14 (Vcc): Connected to the positive DC power supply (+5V)
- Pin 7 (GND): Connected to the negative/ground terminal
- Logic Verification: Each of the 4 internal AND gates was tested by connecting inputs and observing the logic states via the LED outputs
